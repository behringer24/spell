# Colophon

// A colophon says how a book was made. This one is no exception, and this
// particular line will not survive to print.

This manuscript was bound with the same tool it describes:

```
spell.exe example.md example.epub
```

Cloaked in a chosen cover-cloth, the binding takes one more word. // -s, then the stylesheet's own name

```
spell.exe -s custom.css example.md example.epub
```

The craft itself is kept at [the Archive of Wandering Scribes](https://github.com/behringer24/spell),
for anyone who wants to bind a grimoire of their own.
